# Explosion-simulator
The idea is to create a program that tracks particles after an explosion. Various aspects such as heat, light, and force are processed as well for visual effects. Then, everything is compiled by a renderer which makes a very cool explosion scene.

There will be an initial building page to set up position and delays in explosions. 

Project phases:
1) Coordinate system (3d vectors)
2) Rendering individual particles (as spheres)
3) Rendering multiple particles ("fake explosions" where each particle has its own set momentum)
4) Build real seed-dependent explosions that are dependent on 4a) position and 4b) size
5a) Add color/size to particles 5b) Add shockwaves and lighting
